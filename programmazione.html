Laboratorio C con GNU Nano e GCC

Scrivi codice C nel simulatore Nano, compila con GCC simulato e osserva output ed errori — tutto statico, tutto nel browser.

Il compilatore è simulato: riproduce il comportamento di gcc per errori comuni di C (tipi, dichiarazioni, parentesi, ritorno main) ed esegue il programma interpretando le chiamate printf / scanf / strlen / strcmp / strcpy / rand. Perfetto per esercitarsi prima del lab.

Comandi GCC utili

gcc main.c -o main -Wall
gcc main.c -o main -Wall -Wextra
gcc -std=c99 main.c -o out -lm
./main
./main < input.txt

-Wall   avvisi principali
-Wextra avvisi extra
-lm     collega math.h
-std=c99 standard C99
