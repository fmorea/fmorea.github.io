      Riferimenti teorici · scheda Arduino Uno R3, IDE e linguaggio C++
      

        

          
Dalla USB al microcontrollore · pp. 286–290

          
La Uno R3 usa un ATmega328P a 16 MHz. I 14 pin digitali sono numerati da D0 a D13 (PWM su ~3, ~5, ~6, ~9, ~10, ~11). Gli ingressi A0…A5 misurano una tensione rispetto a GND. L è il LED integrato su D13; ON segnala l’alimentazione; RX/TX indicano traffico seriale.

          
Sulla scheda reale, collegala via USB dati, apri Arduino IDE, scegli Arduino Uno e la porta, poi usa Verifica e Carica. Per le stampe apri il Monitor Seriale a 9600 baud.

        

        

          
Come leggere uno sketch · pp. 289–292

          
setup() configura i pin una sola volta all’avvio; loop() si ripete di continuo. Le variabili globali conservano il valore fra un ciclo e l’altro.

          
pinMode imposta OUTPUT, INPUT o INPUT_PULLUP. digitalRead/digitalWrite gestiscono i livelli logici, analogRead(A0) converte 0–5 V in 0–1023 (≈ 4,88 mV/passo), analogWrite genera PWM da 0 a 255.

        

        

          
Condizioni, cicli e funzioni · pp. 292–295

          
Puoi usare if / else, switch / case, for, while, do…while, array e funzioni personalizzate (es. int doppio(int x) { return 2 * x; }).

          
Sono supportate anche millis(), map(), constrain(), min(), max(), abs(), pow(), sqrt(), random(), Serial.print() e Serial.println(). Scheda tecnica Uno R3 ↗

        

      

    


    

      Cosa supporta il simulatore
      
Interpreta sketch C++ Arduino con int, long, unsigned long, float, bool, byte, const, array 1D, funzioni personalizzate, if/else, for, while, do…while, switch/case, break, continue, return e operatori logici/aritmetici (&&, ||, !, +=, ++, --).

      
Supporta pinMode (INPUT, OUTPUT, INPUT_PULLUP), digitalRead, digitalWrite, analogRead (A0–A5), analogWrite (PWM su ~3, ~5, ~6, ~9, ~10, ~11), delay, millis, map, constrain, min, max, abs, pow, sqrt, random, Serial.print e Serial.println. Per progetti con librerie esterne, trasferisci lo sketch in Arduino IDE.
